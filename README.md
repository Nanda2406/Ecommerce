# Tech Fácil

Abra `index.html` no navegador. Não é necessário instalar programas.

## Organização

- `index.html`: estrutura HTML com header, main e footer.
- `css/header.css`: cabeçalho e navegação.
- `css/main.css`: layout principal, produtos, carrinho, painel e cores lilás.
- `css/footer.css`: rodapé.
- `js/app.js`: catálogo, carrinho, pedidos e administração.
- `dados/produtos.csv`: 24 produtos de exemplo.

## Dados

O navegador guarda alterações em `localStorage`. O CSV é fornecido como base e pode ser importado no painel Admin. Se já abriu uma versão anterior, os novos produtos são adicionados sem apagar os antigos. Use o botão de restaurar loja para voltar aos produtos iniciais, se necessário.

A loja funciona localmente e não realiza pagamentos reais nem autenticação de usuários em servidor.
